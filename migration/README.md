- 新增 91 个独立 Markdown 文件；已存在的「力扣 384：打乱数组」只补充原始发布时间与来源，保留原有网址和已修复的正文。

- 每篇文章的 `date` 保留原站日期，`publishedAt` 保留完整 ISO 时间、微秒和 `+08:00` 时区，`source` 保留原文链接。文章顶部展示原始发布时间；不会把迁移日期当成发布日期。

## 核对文件

`kajspace-manifest.json` 记录每篇文章的原站永久 ID、原始标题、完整发布时间、新文件路径、图片来源及修复项。`verification.json` 记录正式构建后的数量与检查结果。

原始页面缓存放在 `.cache/kajspace/`，已排除 Git。缓存只用于迁移核对，日常开发和 GitHub Pages 构建均不依赖它，也不依赖 Python。运行 `npm run docs:build` 即可正常构建网站。

迁移脚本只用 Python 标准库：

```bash
python scripts/migrate_kajspace.py --collect
python scripts/migrate_kajspace.py
npm run docs:build
python scripts/verify_migration.py
```

`--collect` 读取公开页面并复用本地缓存，不登录、不修改原站。重复导入时会校验文件内容哈希，遇到导入后被手动编辑的文件会停止，防止覆盖修改。重新核对需要完整的原始缓存。
