# 项目实践

这里展示值得复盘的个人项目。每个项目都围绕背景、取舍和结果展开，避免只罗列技术名词。

## 项目模板

### 项目名称（待填写）

> 项目状态：规划中 / 开发中 / 已完成

- **项目背景**：说明为什么做，以及服务谁。
- **技术栈**：填写实际使用的框架、语言和基础设施。
- **核心功能**：用 2～4 条描述用户可感知的能力。
- **技术难点**：记录性能、数据一致性、兼容性或协作问题。
- **个人贡献**：说明你负责的设计、开发和验证工作。
- **项目源码**：尚未配置
- **在线演示**：尚未配置

链接配置后再替换“尚未配置”，不要填写无法访问的地址。
