# LeetCode 20. 有效括号

![正文图片](/images/kajspace/2826bfe86fd2c4de.png)

括号匹配使用栈结构来实现。首先，如果字符串长度是奇数，可以直接判定为不匹配，因为括号必须成对出现。然后遍历字符串中的每个字符，遇到左括号（如圆括号、方括号、花括号）就将其压入栈中；遇到右括号时，先检查栈是否为空，如果为空说明没有对应的左括号，匹配失败，否则弹出栈顶元素，利用预先建立的哈希表判断该左括号是否与当前右括号类型匹配，如果不匹配也失败。遍历完所有字符后，还要检查栈是否为空，如果栈中还有剩余元素，说明有多余的左括号未匹配，同样判定为不匹配；只有栈为空才表示所有括号都正确匹配。哈希表的作用是存储每种左括号对应的右括号，这样比较时只需查表，无需编写冗长的条件判断。
