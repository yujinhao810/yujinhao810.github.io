# 93. 复原IP地址

![正文图片](/images/kajspace/544c033d1881d6b8.png)

### 93. 复原 IP 地址 {#kaj-h-4e882601-bda8-42ec-8afa-bb393048264e}

**做题复盘：**

这道题当时对整体思路有些遗忘，最开始想到的是通过在字符串中间隔几个元素插入一个 `.` 来构造 IP 地址，但没有马上想到每一段的长度应该如何确定，以及如何判断每一段是否合法。

后来回忆起来，这道题的关键是 **IP 地址固定由 4 段组成，因此只需要确定前 3 段的切割位置，最后一段自然确定**。可以通过三个 `for` 循环分别枚举前三段的长度，每一段最多取 3 个字符，然后使用 `isValid` 函数判断当前子串是否合法。

合法条件主要有三个：

1. 长度必须在 `1~3` 之间；
2. 多位数字不能以 `0` 开头；
3. 数值不能超过 `255`。

当三个切割点确定后，得到四个子串，依次判断四段是否合法。如果全部合法，就将四段通过 `.` 拼接成一个 IP 地址加入结果。

这里不需要真的在原字符串中不断插入和删除 `.`，只需要记录切割位置，最后通过字符串拼接生成答案即可。之前可能和其他需要实际修改字符串的回溯题混淆了。

**算法总结：**

这道题本质上是一个 **枚举切割点 + 合法性判断** 的问题。

因为 IP 地址只有 4 段，所以可以直接使用三个循环枚举三个切割点：

```text
字符串
 ↓
确定第 1 段
 ↓
确定第 2 段
 ↓
确定第 3 段
 ↓
剩余部分作为第 4 段
 ↓
判断四段是否合法
 ↓
合法 → 拼接成 IP 地址
```

每一段最多 3 个字符，因此每个切割点最多只有 3 种选择。核心不是“插入点”，而是**枚举每一段的长度/切割位置**。

**需要掌握的关键点：**

> 固定 4 段 → 枚举 3 个切割点 → 每段最多 3 位 → `isValid` 判断 → 四段都合法则加入答案。

这道题可以看作一种比较简单的回溯/枚举问题。由于层数固定为 4 层，直接写三个 `for` 循环比通用回溯写法更加直观。
