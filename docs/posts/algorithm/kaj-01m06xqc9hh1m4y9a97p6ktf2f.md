# 146. LRU缓存

![正文图片](/images/kajspace/921a8debcdba6710.png)

做过两遍的题，再做还是有点不熟练，双向链表的插入和删除操作，以及get和put的逻辑，还有核心的节点查找#getNode。这道题的核心思想在于用双向链表实现节点的删除与新增，然后维护一个哈希表**保存 key 到 Node 节点的映射，**这里为什么要用哈希表？答案是为了快速定位节点，如果只有链表，遍历整个链表，时间复杂度是 O(n)，不满足题目要求。  
代码用到了ES6的`class` ，`class` 是 ES6 引入的“类”语法，用来定义一个对象的模板。  
本质上，`class` 还是基于 JavaScript 原有的原型继承实现的，只是写起来更清晰、更像传统的面向对象语言。  
`constructor` 是类里面的构造函数。
