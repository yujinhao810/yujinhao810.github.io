# 104. 二叉树的最大深度

![正文图片](/images/kajspace/ed5b8bd9c8a4d4db.png)

### 104. 二叉树的最大深度 {#kaj-h-13dd42c6-70fb-4d43-970f-619b1305e380}

**算法复盘：**

这道题的思路比较清楚，本质上是通过**递归计算左右子树的最大深度**。

对于当前节点，先分别递归计算它的左子树和右子树的最大深度，然后取两者中较大的一个，最后再 `+1`，其中 `+1` 表示当前节点这一层。

递归关系可以理解为：

```text
当前节点的最大深度
=
max(左子树最大深度, 右子树最大深度) + 1
```

如果当前节点为空，说明已经递归到了树的底部，此时返回 `0`，这也是递归的终止条件。

代码中不需要额外声明一个递归函数，直接递归调用当前的 `maxDepth` 函数即可。

```js
var maxDepth = function(root) {
    if (root === null) {
        return 0;
    }

    return Math.max(
        maxDepth(root.left),
        maxDepth(root.right)
    ) + 1;
};
```

**执行过程：**

以一棵简单的二叉树为例：

```text
        1
       / \
      2   3
     /
    4
```

递归过程：

```text
maxDepth(1)
    ↓
maxDepth(2)        maxDepth(3)
    ↓                  ↓
maxDepth(4)           0
    ↓
   0
```

从最底层开始返回：

```text
节点 4：max(0, 0) + 1 = 1
节点 2：max(1, 0) + 1 = 2
节点 3：max(0, 0) + 1 = 1
节点 1：max(2, 1) + 1 = 3
```

所以最终最大深度为 `3`。

---

### 关键理解 {#kaj-h-02e42254-c9f0-4d4b-b987-2a7362d09380}

这道题最重要的是理解：

> **一个节点的最大深度，取决于它左右子树中深度更大的那一棵。**

因为我们求的是**最长路径**，所以不能把左右子树的深度相加，而是：

```text
max(左子树深度, 右子树深度) + 当前节点这一层
```

另外，递归函数的返回值就是“当前节点这棵树的最大深度”，所以可以直接利用函数自身完成递归，不需要额外定义 `depth()` 之类的辅助函数。

### 一句话记忆 {#kaj-h-0ae1892e-0587-4f80-8305-00b845c7267b}

> **当前节点最大深度 = 左右子树最大深度的较大值 + 1；空节点返回 0。**

这道题可以作为二叉树递归的基础模板：

```text
先判断空节点
    ↓
递归左子树
    ↓
递归右子树
    ↓
根据左右结果计算当前节点
    ↓
返回结果
```
