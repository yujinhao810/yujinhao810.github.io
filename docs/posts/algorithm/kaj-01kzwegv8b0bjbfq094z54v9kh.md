# LeetCode 415. 字符串相加

![正文图片](/images/kajspace/aaf59d68657af83b.png)

由于题目限制只能使用字符串实现加法，我采用模拟小学竖式加法的方式。具体做法是：设置双指针分别从两个字符串的个位开始向前遍历，同时维护一个进位变量。每位相加时，利用ASCII码将字符转换为数字；若某一字符串已遍历完，则用0补足，继续与另一位相加。每轮计算后将当前位结果存入字符数组，最后检查进位是否为0，若非0则需追加到数组末尾。完成所有位运算后，将字符数组反转并转换为字符串返回。
