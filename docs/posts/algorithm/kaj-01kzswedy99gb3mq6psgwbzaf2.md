# 165. 比较版本号

版本号由被'.'分开的修订号组成，所以我们可以先把版本号字符串转为数组，间隔就是'.'；由于修订号的长度是不一致的，所以需要比较版本号数组长度来进行遍历对比，缺失的修订号统一视为0；同时通过parseInt讲字符串转换为number类型；最后根据比较结果返回1/-1/0
