# LeetCode 206. 反转链表

![正文图片](/images/kajspace/6042efdea2d7c92b.png)

构造一个链表最基础的两种方法是什么？头插法和尾插法。

**头插法：**首先思考头插法，那么开始的节点就是处于链表末尾的节点，我们从链表头开始遍历，每遍历到一个节点，就将它插入到新链表的头部。但是在修改当前节点 `cur` 的 `next` 时，如果直接修改 `cur.next = pre`，就会丢失原来 `cur` 后面的链表。因此我们利用双指针 `pre` 和 `cur` 分别代表前一个节点和当前节点，并在修改 `cur.next` 之前，先用 `next` 暂存 `cur.next`，这样修改完成后，就可以通过 `next` 找到剩余的链表，继续向后遍历。

**尾插法：**再思考尾插法，既然每次都要把当前节点插入到新链表的尾部，那么首先需要知道原链表的末尾节点，因为它会成为反转链表的新头节点。因此递归比较适合这种思路，我们先不断递归向后，直到到达链表末尾，将末尾节点作为新链表的头节点；然后在递归返回的过程中，把当前节点依次插入到已经反转好的链表尾部，并将当前节点的 `next` 置为 `null`，最终得到反转后的链表。
