# 62. 不同路径

首先思考原问题是从（0，0）到（2，6），那最后一步是什么？  

如果从 (1,6) 向下走到终点 (2,6)，那么要解决的问题是从起点 (0,0) 走到 (1,6) 的路径数。

如果从 (2,5) 向右走到终点 (2,6)，那么要解决的问题是从起点 (0,0) 走到 (2,5) 的路径数。  

有了这些规模更小的子问题，我们就可以用递归解决。  
递归搜索 + 保存递归返回值  

进一步的，我们可以把递归转化为递推，即自底向上的动态规划，循环+dp数组
