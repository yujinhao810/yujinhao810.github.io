# 200.岛屿数量 + 300. 最长上升子序列

## 算法题复盘总结 {#kaj-h-d6a5663c-4561-4601-a4b5-dad5b30018f7}

![正文图片](/images/kajspace/d41f4c4d8488dc4b.png)![正文图片](/images/kajspace/c713b15a9eb70e4d.png)

目前这几道题的情况是：**基本能够独立想到解题思路，但具体实现时还需要思考一会，写完后通过几次调试解决细节问题，最终能够通过测试。**

### 1. 岛屿数量 —— DFS / 递归 {#kaj-h-3f255721-83ae-4dda-9c08-b0868e2882c0}

**核心思路：**

把二维网格看成一个地图，遍历所有元素：

1. 如果当前元素是 `'1'`，说明发现了一块新的岛屿，岛屿数量 `+1`。
2. 从当前点开始进行 `dfs`，把属于这座岛屿的所有陆地都搜索出来。
3. 搜索过程中，将访问过的 `'1'` 修改成 `'2'`，作为**访问标记**，避免后续重复搜索。
4. 每个陆地点继续向**上、下、左、右**四个方向递归。
5. 直到当前岛屿所有相连的 `'1'` 都被搜索并标记完，再继续遍历其他位置。

**最核心的思想：**

> **遍历发现岛屿 → DFS 把整座岛屿搜索完 → 标记访问过的节点 → 防止重复计算。**

可以记成：

```text
遇到 '1'
   ↓
岛屿数量 + 1
   ↓
DFS
   ↓
标记当前点
   ↓
递归上下左右
   ↓
把整个岛屿“淹掉”
```

### 2. 最长上升子序列 —— 动态规划 {#kaj-h-7e1b6381-7d9b-45d4-8b52-e1288e46404f}

**核心思路：**

维护一个 `dp` 数组：

```text
dp[i]
```

表示：

> **以** `nums[i]` **作为最后一个元素时，最长递增子序列的长度。**

初始化：

```js
const dp = Array(nums.length).fill(1);
```

因为每个元素至少可以单独构成一个长度为 `1` 的递增子序列。

然后使用两个 `for`：

```js
for (let i = 1; i < nums.length; i++) {
    for (let j = 0; j < i; j++) {
        ...
    }
}
```

#### 外层 `i` {#kaj-h-95c32e07-edc9-434e-b0e9-462ffedbb36b}

表示：

> **当前正在计算** `nums[i]` **的最长递增子序列。**

#### 内层 `j` {#kaj-h-ffa77cfd-17ce-4400-9dde-28d2ededbb07}

表示：

> **遍历** `i` **前面的所有元素，寻找谁可以接在** `nums[i]` **前面。**

如果：

```text
nums[j] < nums[i]
```

说明 `nums[i]` 可以接在以 `nums[j]` 结尾的递增子序列后面：

```text
dp[i] = Math.max(dp[i], dp[j] + 1);
```

最后：

```text
Math.max(...dp)
```

得到整个数组的最长递增子序列长度。

### LIS 最核心的三个东西 {#kaj-h-dd423b20-bc1f-489f-8c1c-da9aab251cba}

这道题不要死记代码，重点记住下面三个东西：

```text
dp[i]：以 nums[i] 结尾的最长递增子序列长度

i：我现在要计算哪个位置

j：我在前面找谁可以接到 nums[i] 前面
```

进一步可以浓缩成一句话：

> **固定** `i`**，向前找** `j`**；如果** `nums[j] < nums[i]`**，就尝试把** `nums[i]` **接到** `j` **后面，用** `dp[j] + 1` **更新** `dp[i]`**。**

## 两道题的思维模式 {#kaj-h-e2ac4ba4-a519-45e8-a12c-c7f1bff58c66}

这两道题虽然算法不同，但都体现了一个很重要的刷题思路：

### 岛屿数量 {#kaj-h-585353fd-e340-4315-88d0-794ca3211a1f}

关注：

> **当前节点和周围节点有什么关系？**

所以想到：

```text
树/网格 → DFS → 递归搜索相邻节点
```

### 最长上升子序列 {#kaj-h-ecb1b18b-26a7-42ab-a541-0e5c20a87190}

关注：

> **当前元素和前面的元素有什么关系？**

所以想到：

```text
重复子问题 → DP → dp[i]记录状态
```

## 最后形成自己的刷题模板 {#kaj-h-6f475d9e-6282-4040-86ed-1a565110f794}

目前可以把这两道题分别记成：

```text
岛屿数量：

遍历网格
→ 遇到 '1'
→ 发现新岛屿
→ DFS
→ 标记访问
→ 上下左右扩散
→ 搜完整座
```

```text
最长上升子序列：

定义 dp[i]
→ dp[i] 表示以 nums[i] 结尾的 LIS 长度
→ 固定 i
→ 向前遍历 j
→ nums[j] < nums[i]
→ dp[i] = max(dp[i], dp[j] + 1)
→ 最后取 max(dp)
```
