# 215. 数组中的第K个最大元素

![正文图片](/images/kajspace/b4a20e717567e518.png)

快速选择排序，但有几个关键点必须要想明白，第一，为什么要随机选择一个基准元素，第二，交换的条件是什么，以及怎么样避免算法的时间复杂度退化。然而，如果按照 &lt;pivot 和 ≥pivot 划分数组，这个做法会在数组包含大量重复元素时，划分后的 i 往往是子数组第一个元素的下标，算法会退化至 O(n^2)。  
解决办法：把 &lt; 改成 ≤，也就是把 ≤pivot 的元素放在 pivot 的左侧，把 ≥pivot 的元素放在 pivot 的右侧。特别地，如果子数组所有元素都相同，这样做可以完美地返回子数组的中心下标（见代码），避免复杂度退化。
