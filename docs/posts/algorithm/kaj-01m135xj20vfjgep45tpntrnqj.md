# 56. 合并区间

![正文图片](/images/kajspace/30d30b9dd3d85392.png)

整体思路是有的，主要卡住的点在于最终合并后的区间数组的选择，其实只要选择最后一个数组即可，因为前面的不需要合并了。

首先将 `intervals` 按照每个区间的**左端点升序排序**，这样可以保证后面的区间左端点一定不会小于前面的区间。然后遍历排序后的 `intervals`，维护一个 `ans` 数组，用于存放最终合并后的区间。

对于当前区间 `p`，如果 `ans` 为空，直接将 `p` 加入 `ans`。否则取 `ans` 中的最后一个区间 `last` 进行比较。

如果 `p[0] > last[1]`，说明当前区间的左端点已经超过了上一个合并区间的右端点，两者不存在重叠，因此直接将 `p` 加入 `ans`。

如果 `p[0] <= last[1]`，说明两个区间存在重叠，需要进行合并。合并后的左端点仍然是 `last[0]`，右端点取 `last[1]` 和 `p[1]` 中的较大值，即：

```text
last[1] = Math.max(last[1], p[1]);
```

由于区间已经按照左端点排序，所以当前区间只需要和 `ans` 中的**最后一个区间**比较，不需要再遍历 `ans` 中前面的区间。

**算法思路表述：先**按照区间左端点升序排序，然后遍历所有区间，并维护一个 `ans` 保存合并结果。每次只需要拿当前区间和 `ans` 的最后一个区间比较。如果当前区间的左端点大于最后区间的右端点，说明没有重叠，直接加入 `ans`；否则说明有重叠，将两个区间合并，右端点取两者右端点的最大值。由于已经按照左端点排序，所以只需要比较 `ans` 的最后一个区间即可。
