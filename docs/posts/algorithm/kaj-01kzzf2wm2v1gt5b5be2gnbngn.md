# 102. 二叉树的层序遍历

![正文图片](/images/kajspace/8c907ba081fa1f3c.png)

这道题要求**按照层级遍历一棵二叉树**，也就是先遍历第一层，再遍历第二层、第三层……因此我首先想到用数组来模拟每一层的节点。具体来说，用 `cur` 数组存储**当前层的所有节点**，遍历 `cur` 的过程中，将每个节点的 `val` 存入 `vals` 数组，用于记录当前层的遍历结果；同时判断当前节点是否存在左右子节点，如果存在，就依次放入 `nxt` 数组，作为下一层需要遍历的节点。当前层遍历完成后，说明这一层已经处理完毕，此时将 `cur` 更新为 `nxt`，开始遍历下一层；同时将当前层的 `vals` 放入最终结果 `ans` 中。这样通过 `cur → nxt` 的不断更新，就可以保证**一次只处理一层节点**，最终得到按层划分的遍历结果。
