# LeetCode 1. 两数之和

![正文图片](/images/kajspace/c5208ec76c92cbf5.png)

想要做出这道题非常简单，两个for循环搞定，但时间复杂度O（n^2），因此，怎么样降低时间复杂度呢，我想到了可以采用**哈希表（Map）**来存储已遍历过的元素及其下标。在遍历数组时，对于当前元素，计算目标值与它的差值，若该差值已在 Map 中存在，则说明找到了匹配的两个数，直接返回它们的下标，这种策略本质上是**“用空间换时间”**，值得学习。
