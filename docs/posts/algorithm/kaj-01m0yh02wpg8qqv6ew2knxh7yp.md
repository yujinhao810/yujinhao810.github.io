# JS算法题：数组转树

这道题我拿到之后，整体思路其实是有的，就是先找到根节点，然后根据 `parentId` 建立父子关系，只是当时没有马上想到具体怎么实现。看了题解之后，发现可以用 **两遍** `forEach` **+** `Map` 来实现。

第一遍遍历数组，建立一个 `id → 节点对象` 的映射，存到 `Map` 中。这样后面可以通过 `parentId` 快速找到对应的父节点。

第二遍再遍历原数组，根据当前节点的 `parentId` 来判断它应该放在哪里：

- 如果 `parentId === null`，说明当前节点没有父节点，是**根节点**，直接放进最终结果 `result` 中。
- 如果 `parentId !== null`，就通过 `map.get(item.parentId)` 找到它对应的父节点，然后执行 `parent.children.push(node)`，把当前节点添加到父节点的 `children` 中。

这里使用 `Map` 的好处是可以通过 `id` 快速找到父节点，而不需要每次再遍历整个数组去查找，整体时间复杂度可以做到 **O(n)**。

另外，每个节点在第一遍的时候都会初始化一个 `children: []`，所以即使是叶子节点，也会保留一个空的 `children` 数组，保证所有节点的数据结构一致。

另一种方法是使用**递归**，这也是我看了题解之后了解到的。相比第一种 `Map + 两次遍历` 的方法，这种方式实现起来比较直观，但是由于每次递归都会重新遍历整个 `list`，所以时间复杂度更高，最坏情况下是 **O(n²)**。

具体实现上，定义一个递归函数 `loop(parentId)`，它的作用就是：**寻找所有** `parentId` **等于当前传入** `parentId` **的节点，也就是找到这个父节点下面的所有子节点。**

函数内部首先创建一个 `res` 数组，然后遍历整个 `list`。如果发现当前节点的 `pid === parentId`，说明找到了当前父节点的一个子节点。

接下来给这个节点递归调用 `loop(item.id)`，继续寻找它自己的子节点，并把递归返回的结果赋值给它的 `children`：

```text
item.children = loop(item.id);
```

最后再把当前节点放进 `res`：

```text
res.push(item);
```

遍历结束后返回 `res`。这样上一层递归就可以把这个结果作为当前节点的 `children`，最终从根节点开始，一层一层递归构建出完整的树。
