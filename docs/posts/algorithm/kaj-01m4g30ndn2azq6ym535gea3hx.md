# 105. 从前序与中序遍历序列构造二叉树

<span id="kaj-h-4ce49a77-1a11-4573-b6ba-637556136265"></span>

## 一、题目描述 {#kaj-h-550a245f-026e-4be5-8c83-19d4d4d59093}

给定两个整数数组 `preorder` 和 `inorder`，其中 `preorder` 是二叉树的前序遍历，`inorder` 是同一棵二叉树的中序遍历。

请构造并返回这棵二叉树。

假设树中不存在重复的元素。

**示例：**

```text
preorder = [3, 9, 20, 15, 7];
inorder  = [9, 3, 15, 20, 7];
```

构造得到的二叉树为：

```text
       3
      / \
     9   20
        /  \
       15   7
```

## 二、核心思路 {#kaj-h-43b4be1b-011a-477c-ac7d-ea8706e4ce08}

这道题的核心是利用前序遍历和中序遍历的特点，确定根节点，并划分左右子树。

### 1. 前序遍历确定根节点 {#kaj-h-5b180bb1-bf66-4fbb-a6a0-ed8bdaff0cbe}

前序遍历的顺序为：

```text
根节点 → 左子树 → 右子树
```

因此，当前子树在前序遍历中的第一个元素就是根节点。

例如：

```text
preorder = [3, 9, 20, 15, 7];
```

根节点就是 `3`。

### 2. 中序遍历确定左右子树 {#kaj-h-e40aaf0d-d9b0-4a91-9926-a1b7494efe97}

中序遍历的顺序为：

```text
左子树 → 根节点 → 右子树
```

例如：

```text
inorder = [9, 3, 15, 20, 7];
```

根节点 `3` 左边的元素属于左子树，右边的元素属于右子树。

因此：

```text
左子树 = [9];
右子树 = [15, 20, 7];
```

通过根节点在中序遍历中的位置，可以计算左子树的节点数量，进而确定左右子树在前序遍历中的范围。

### 3. 递归构造二叉树 {#kaj-h-da2037f1-98d2-45d1-985e-df7ea8a0aad5}

确定当前根节点后，分别递归构造左子树和右子树，最后创建当前根节点并连接左右孩子。

递归终止条件是当前子树为空，此时返回 `null`。

整体过程可以概括为：

1. 从前序遍历中找到当前根节点。
2. 根据中序遍历中根节点的位置计算左子树大小。
3. 划分左子树和右子树的遍历区间。
4. 递归构造左右子树。
5. 创建当前根节点并返回。

## 三、优化思路：使用下标代替数组切片 {#kaj-h-86df87a3-1a44-47e8-a97e-d701596e497b}

最直观的解法是使用 `slice()` 将前序遍历和中序遍历划分成多个新数组，再递归处理。

但这种方法会反复创建和复制数组，增加额外开销。

因此，可以优化为：**递归过程中不创建新数组，而是通过下标维护当前子树的范围。**

同时，使用 `Map` 预先记录每个节点在中序遍历中的下标，避免每次递归都通过 `indexOf()` 查找。

### 1. 建立 Map {#kaj-h-42aae228-8ca5-4749-8ba1-5f7c074070c5}

```js
const index = new Map();

for (let i = 0; i < n; i++) {
    index.set(inorder[i], i);
}
```

例如：

```text
节点值    中序遍历下标
  9            0
  3            1
 15            2
 20            3
  7            4
```

之后，可以通过 `index.get(rootVal)` 平均以 的时间获取根节点在中序遍历中的位置。

### 2. 设计递归函数 dfs {#kaj-h-66ed7664-728b-4429-bde5-c0d2ed98de8c}

```js
function dfs(preL, preR, inL)
```

三个参数分别表示：

- `preL`：当前子树在前序遍历中的起始下标，包含。
- `preR`：当前子树在前序遍历中的结束下标，不包含。
- `inL`：当前子树在中序遍历中的起始下标，包含。

前序遍历采用左闭右开区间 `[preL, preR)`。

例如：

```text
dfs(0, 5, 0);
```

表示从整个前序遍历区间 `[0, 5)` 开始构造整棵二叉树，中序遍历的起始下标为 `0`。

为什么不需要传递中序遍历的右边界 `inR`？

因为当前子树的节点数量等于前序遍历区间的长度：

```js
const size = preR - preL;
```

所以中序遍历的范围可以推导为：

```text
[inL, inL + size)
```

因此，只需要传入 `inL`，就可以确定中序遍历的完整区间。

## 四、递归区间的推导 {#kaj-h-1e0ac102-e296-4114-9c6a-0b47d84c95ca}

这是本题最关键的部分。

### 1. 递归终止条件 {#kaj-h-8eb11c94-0d07-42ee-85a2-0f1608af8cdc}

```js
if (preL === preR) {
    return null;
}
```

由于使用左闭右开区间，当 `preL === preR` 时，当前区间没有元素，说明当前子树为空，返回 `null`。

### 2. 确定根节点 {#kaj-h-441aa57e-6401-4587-9c27-be54b23f02b5}

```js
const rootVal = preorder[preL];
```

前序遍历遵循根左右的顺序，因此 `preorder[preL]` 就是当前子树的根节点。

### 3. 计算左子树大小 {#kaj-h-0a0842e1-0f6e-49f6-bea8-6cbe1a439d17}

```js
const leftSize = index.get(rootVal) - inL;
```

其中：

- `index.get(rootVal)`：根节点在中序遍历中的下标。
- `inL`：当前子树在中序遍历中的起始下标。

两者相减，得到根节点左侧的节点数量，即左子树大小。

例如：

```text
preorder = [3, 9, 20, 15, 7];
inorder  = [9, 3, 15, 20, 7];
```

第一次调用：

```text
dfs(0, 5, 0);
```

当前根节点为：

```text
preorder[0] = 3;
```

根节点 `3` 在中序遍历中的下标为 `1`，所以：

```text
leftSize = 1 - 0; // 1
```

说明左子树有一个节点。

### 4. 划分左子树区间 {#kaj-h-4d7edc51-f406-47b3-b6c8-81ae306f085c}

前序遍历的结构为：

```text
根节点 | 左子树 | 右子树
```

根节点占用一个位置，左子树占用 `leftSize` 个位置。

因此，左子树的前序遍历区间为：

```text
[preL + 1, preL + 1 + leftSize)
```

递归调用：

```js
const left = dfs(
    preL + 1,
    preL + 1 + leftSize,
    inL
);
```

中序遍历中，左子树位于根节点之前，所以左子树的起始下标仍然是 `inL`。

### 5. 划分右子树区间 {#kaj-h-e3467006-1b8d-4606-8f5a-77c4ddafd264}

前序遍历中，根节点和左子树之后的部分就是右子树。

因此，右子树的前序遍历区间为：

```text
[preL + 1 + leftSize, preR)
```

中序遍历中，右子树从根节点之后开始，因此右子树的起始下标为：

```text
inL + leftSize + 1
```

递归调用：

```js
const right = dfs(
    preL + 1 + leftSize,
    preR,
    inL + 1 + leftSize
);
```

### 6. 创建根节点 {#kaj-h-7429fca6-3ed2-4ef8-86d0-86b67584eff0}

左右子树递归完成后，创建当前根节点：

```js
return new TreeNode(rootVal, left, right);
```

这里的 `left` 和 `right` 是递归返回的二叉树节点，而不是数组。

## 五、完整代码 {#kaj-h-3127846f-39ba-4a5c-9c86-e7710f611048}

```js
var buildTree = function(preorder, inorder) {
    const n = preorder.length;

    // 记录每个节点在中序遍历中的下标
    const index = new Map();

    for (let i = 0; i < n; i++) {
        index.set(inorder[i], i);
    }

    // 根据前序遍历区间 [preL, preR)
    // 和中序遍历起点 inL 构造二叉树
    function dfs(preL, preR, inL) {
        // 空区间，返回空节点
        if (preL === preR) {
            return null;
        }

        // 前序遍历的第一个元素是当前根节点
        const rootVal = preorder[preL];

        // 计算左子树大小
        const leftSize = index.get(rootVal) - inL;

        // 递归构造左子树
        const left = dfs(
            preL + 1,
            preL + 1 + leftSize,
            inL
        );

        // 递归构造右子树
        const right = dfs(
            preL + 1 + leftSize,
            preR,
            inL + 1 + leftSize
        );

        // 创建当前根节点并连接左右子树
        return new TreeNode(rootVal, left, right);
    }

    // 从整个前序遍历区间开始构造
    return dfs(0, n, 0);
};
```

## 六、递归过程示例 {#kaj-h-ae0763f2-90c1-465b-afc0-6bf9c5139a35}

输入：

```text
preorder = [3, 9, 20, 15, 7];
inorder  = [9, 3, 15, 20, 7];
```

### 第一次调用：构造节点 3 {#kaj-h-08c67762-1a0b-4676-b56f-030b754c11f0}

```text
dfs(0, 5, 0);
```

根节点为 `3`，左子树大小为 `1`。

先构造左子树：

```text
dfs(1, 2, 0);
```

### 第二次调用：构造节点 9 {#kaj-h-fb8dc524-800b-4606-95f5-938803ddfa7b}

```text
dfs(1, 2, 0);
```

根节点为 `9`，左子树大小为 `0`。

左右子树分别递归到空区间，返回 `null`。

于是返回：

```text
new TreeNode(9, null, null);
```

节点 `9` 返回给第一层调用，赋值给 `left`。

### 回到第一层：构造右子树 {#kaj-h-7ad8471c-d36c-4176-b1c1-d5cfe81e0a67}

第一层继续执行：

```text
dfs(2, 5, 2);
```

当前根节点为 `20`，左子树大小为 `1`。

先构造左子树：

```text
dfs(3, 4, 2);
```

返回叶子节点 `15`。

再构造右子树：

```text
dfs(4, 5, 4);
```

返回叶子节点 `7`。

节点 `20` 的左右子树都完成后，返回：

```text
new TreeNode(20, left, right);
```

最后回到第一层，节点 `3` 的左右子树都已完成，返回：

```text
new TreeNode(3, left, right);
```

最终得到：

```text
       3
      / \
     9   20
        /  \
       15   7
```

**递归执行顺序总结：**

1. 确定根节点。
2. 递归构造左子树，当前调用暂停。
3. 左子树返回后，递归构造右子树。
4. 右子树返回后，创建当前根节点。
5. 将构造好的节点返回给上一层。

需要注意，递归调用并不是同时执行的。程序会先执行左子树递归，等它返回后，再执行右子树递归。

## 七、复杂度分析 {#kaj-h-82d9d320-670f-47c5-bc86-85917bdffef7}

设二叉树共有 `n` 个节点。

### 时间复杂度：`O(n)` {#kaj-h-0a7d4769-096e-49af-9b6b-d769891ec1f6}

- 构建 `Map` 需要 `O(n)` 时间。
- 每个节点只会被构造一次。
- 每次 `Map.get()` 平均为 `O(1)`。
- 每次递归只进行常数次操作，不再复制数组。

因此，总时间复杂度为 `O(n)`。

### 空间复杂度：`O(n)` {#kaj-h-73c3d2e3-9535-427d-a533-42a168a09542}

- `Map` 存储所有节点的位置，占用 `O(n)` 空间。
- 递归调用栈最坏需要 `O(n)` 空间，例如二叉树退化为链表的情况。

因此，辅助空间复杂度为 `O(n)`。

## 八、总结 {#kaj-h-3e760680-d723-4c01-92fe-97fb3b10e8f1}

本题的核心不是简单地遍历数组，而是通过两个遍历序列之间的关系，确定每棵子树的根节点和范围。

需要掌握以下三个关键点：

1. **前序遍历确定根节点**：`preorder[preL]`。
2. **中序遍历确定左子树大小**：`index.get(rootVal) - inL`。
3. **通过区间递归构造左右子树**：利用 `leftSize` 推导左右子树在前序遍历中的范围，以及它们在中序遍历中的起始下标。

最后，使用 `Map` 加下标区间代替 `indexOf()` 和 `slice()`，将时间复杂度优化到 `O(n)`。

这种方法体现了二叉树递归题的一个重要思想：**先确定当前节点，再划分子问题，通过递归解决子问题，最后组合结果。**
