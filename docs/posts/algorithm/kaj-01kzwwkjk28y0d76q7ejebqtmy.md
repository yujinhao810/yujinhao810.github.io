# 46. 全排列

![正文图片](/images/kajspace/8e9b0602c2dd597a.png)

针对全排列问题，我们采用回溯法，并通过递归函数 `dfs(i)` 逐位构建排列，其中 `i`表示当前填充的位置索引；为了在每一步都能判断某个元素是否已被使用，我们需要维护一个布尔型的标记数组 `onPath`，当 `onPath[i]` 为 `true` 时表示 `nums[i]` 已被选入当前路径。递归的核心流程是：当 `i`等于 `nums.length` 时，说明所有位置已填满，此时记录当前排列并终止该层递归；若未填满，则遍历整个 `nums` 数组，每当遇到一个未被使用的元素，便执行“选择-递归-撤销”的标准回溯三步曲——先将该元素填入当前位置并修改标记状态，然后递归调用 `dfs(i+ 1)` 去填充下一位，待递归返回后必须同步撤销刚才的选择（重置标记并移除元素），从而完整地恢复到之前的状态，以便尝试下一个可行元素；需要特别留意的是，递归的终止判断是 `i === n`（恰好填满），而不是 `i > n`，因为一旦索引越界就意味着路径已全部构建完毕。
