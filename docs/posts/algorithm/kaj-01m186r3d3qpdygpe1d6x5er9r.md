# 129. 求根节点到叶节点数字之和

![正文图片](/images/kajspace/69eada700a5c24e5.png)

知道这道题需要使用递归，但当时对递归的入口、递归函数每次具体做什么，思路还不够明确。看完代码后才理解，核心是将当前节点的累加值作为参数传递给下一层节点；如果遍历到叶子节点，就将当前路径的累加值累加到最终答案 `ans` 中。递归过程本质上就是不断递归遍历当前节点的左子树和右子树，并在遍历过程中判断当前节点是否为叶子节点。

总体来说，这道题虽然理解了递归的实现方式，但还不能独立、清晰地推导出递归思路，对递归的掌握还不够扎实，需要继续巩固。
