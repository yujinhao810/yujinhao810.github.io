# 1143. 最长公共子序列

![正文图片](/images/kajspace/d9bb55de1c593160.png)

## 最长公共子序列——动态规划算法总结 {#kaj-h-5d27e0a7-2354-484a-9ab8-6e04bf5b7332}

这道题给定两个字符串 `text1` 和 `text2`，要求找到它们的**最长公共子序列**，返回最长公共子序列的长度。

首先想到使用动态规划。

### 1. 确定 DP 数组含义 {#kaj-h-972c4744-5312-4e59-aae9-16268a029b68}

题目要求的是两个字符串的最长公共子序列。

我们可以从最后一个字符开始倒推：

如果当前考虑的是 `text1` 的第 `i` 个字符和 `text2` 的第 `j` 个字符，那么可以继续考虑它们前面的字符。

因此定义二维数组：

```text
dp[i][j]
```

表示：

> `text1` 的前 `i` 个字符和 `text2` 的前 `j` 个字符，它们的最长公共子序列长度。

例如：

```text
text1 = "abc"
text2 = "ac"
```

那么：

```text
dp[3][2]
```

表示：

> `"abc"` 和 `"ac"` 的最长公共子序列长度。

答案就是：

```text
dp[m][n]
```

其中：

```text
m = text1.length
n = text2.length
```

---

### 2. 为什么 DP 数组开 `m + 1` 行、`n + 1` 列？ {#kaj-h-7e002f98-865a-4d7d-973f-d34be537bc7d}

因为我们需要表示：

```text
前 0 个字符
前 1 个字符
前 2 个字符
...
前 m 个字符
```

所以一共有 `m + 1` 种情况。

同理，第二个字符串有 `n + 1` 种情况。

因此：

```js
const dp = Array.from(
    { length: m + 1 },
    () => Array(n + 1).fill(0)
);
```

其中：

```text
dp[0][j] = 0
dp[i][0] = 0
```

表示其中一个字符串没有字符，那么两者的公共子序列长度一定是 `0`。

---

### 3. 确定状态转移 {#kaj-h-d2c8679f-efca-4d13-b099-640083527d6a}

接下来考虑：

```text
text1[i - 1]
text2[j - 1]
```

也就是两个字符串当前正在比较的最后一个字符。

#### 情况一：两个字符相等 {#kaj-h-0dd04b9b-a202-4ebd-8685-311b1c4ab860}

如果：

```js
text1[i - 1] === text2[j - 1]
```

说明这两个字符可以匹配，并且可以把这个字符加入公共子序列。

例如：

```text
text1：a b c
          ↑
          c

text2：a d c
          ↑
          c
```

两个 `c` 相等，那么我们可以把这两个 `c` 加入公共子序列。

去掉这两个 `c` 后，剩下：

```text
ab
ad
```

所以只需要知道：

```text
dp[i - 1][j - 1]
```

也就是前面两个字符串的最长公共子序列长度。

然后再加上当前匹配的字符：

```text
dp[i][j] = dp[i - 1][j - 1] + 1;
```

可以理解成：

> **相等 → 两个字符可以配对 → 看前面的最优结果 → 再加当前这个字符。**

---

#### 情况二：两个字符不相等 {#kaj-h-0d13cdf5-f266-4deb-af00-e1d22de63d6d}

如果：

```text
text1[i - 1] !== text2[j - 1]
```

说明这两个字符不能直接匹配。

这时候不知道应该舍弃哪个字符，所以分别考虑两种情况：

第一种：

```text
dp[i - 1][j]
```

表示舍弃 `text1` 当前字符，继续比较：

```text
text1 的前 i-1 个字符
text2 的前 j 个字符
```

第二种：

```text
dp[i][j - 1]
```

表示舍弃 `text2` 当前字符，继续比较：

```text
text1 的前 i 个字符
text2 的前 j-1 个字符
```

两种情况都尝试，取较大的那个：

```text
dp[i][j] = Math.max(
    dp[i - 1][j],
    dp[i][j - 1]
);
```

可以理解成：

> **不相等 → 当前两个字符不能配对 → 不知道应该舍弃谁 → 分别尝试舍弃一个 → 取最优结果。**

---

### 4. 确定遍历顺序 {#kaj-h-244c64d2-fc3f-407b-a06b-fc97df822543}

因为：

```text
dp[i][j]
```

依赖：

```text
dp[i - 1][j - 1]
dp[i - 1][j]
dp[i][j - 1]
```

所以这些位置必须提前计算。

因此从左上角开始：

```js
for (let i = 1; i <= m; i++) {
    for (let j = 1; j <= n; j++) {
        ...
    }
}
```

按照从上到下、从左到右的顺序计算整个 DP 表。

---

### 5. 最终代码 {#kaj-h-27f71fab-722a-4b82-aa18-42e6a2dcd080}

```js
var longestCommonSubsequence = function(text1, text2) {
    const m = text1.length;
    const n = text2.length;

    const dp = Array.from(
        { length: m + 1 },
        () => Array(n + 1).fill(0)
    );

    for (let i = 1; i <= m; i++) {
        for (let j = 1; j <= n; j++) {

            if (text1[i - 1] === text2[j - 1]) {
                dp[i][j] = dp[i - 1][j - 1] + 1;
            } else {
                dp[i][j] = Math.max(
                    dp[i - 1][j],
                    dp[i][j - 1]
                );
            }
        }
    }

    return dp[m][n];
};
```

## 6. 做这道题时的完整思考流程 {#kaj-h-16e9bd4b-809d-4e02-a31c-194523300828}

以后重新遇到这道题，可以按照下面的顺序想：

```text
要求：
最长公共子序列
        ↓
想到动态规划
        ↓
当前问题是什么？
        ↓
text1 前 i 个字符
和
text2 前 j 个字符
的最长公共子序列
        ↓
定义：
dp[i][j]
        ↓
比较 text1[i-1] 和 text2[j-1]
        ↓
      是否相等？
       /      \
     是        否
     ↓          ↓
一起匹配      不能匹配
     ↓          ↓
左上角+1     舍弃其中一个
                ↓
             上、左取最大
```

最终得到：

```text
相等：
dp[i][j] = dp[i-1][j-1] + 1

不相等：
dp[i][j] = max(dp[i-1][j], dp[i][j-1])
```

### 一句话记忆 {#kaj-h-1fd48ba4-163a-4cfa-8c95-26a362ac8cca}

> **先定义** `dp[i][j]`**：两个字符串前** `i`**、前** `j` **个字符的 LCS 长度；然后比较当前两个字符，相等就左上角** `+1`**，不相等就上面和左边取最大。**
