# 22. 括号生成

![正文图片](/images/kajspace/f1a84be7186c5706.png)

### 22. 括号生成——算法与做题思路 {#kaj-h-cb744577-7cce-48c6-b624-5c77926aa7a0}

这道题使用**回溯算法**，核心思路是通过递归不断尝试添加 `(` 或 `)`，并利用条件提前排除不合法的情况。

**做题思路：**

1. 因为有 `n` 对括号，所以最终字符串长度一定是 `2 * n`，并且 `(`、`)` 各使用 `n` 个。
2. 定义递归函数 `backtrack(path, left, right)`：

   

   - `path`：当前已经生成的括号字符串；
   - `left`：已经使用的左括号数量；
   - `right`：已经使用的右括号数量。
3. 每次递归有两种选择：

   

   - 如果 `left < n`，可以继续添加 `(`；
   - 如果 `right < left`，可以添加 `)`，保证任何时候右括号数量都不会超过左括号数量。
4. 当 `path.length === 2 * n` 时，说明已经生成一个完整的合法括号组合，将其加入 `ans`。
5. 递归过程中，一条路径探索结束后会返回上一层，再尝试另一种选择，这就是**回溯**。

**核心可以总结为：**

> **回溯遍历所有可能的括号组合，通过** `left < n` **控制左括号数量，通过** `right < left` **保证括号始终合法；当左右括号都使用完时，将当前结果加入答案。**

复习这道题时重点记住这个回溯框架：

```text
当前状态
  ↓
选择 "(" 或 ")"
  ↓
判断选择是否合法
  ↓
递归继续生成
  ↓
走到底
  ↓
返回上一层
  ↓
尝试另一种选择
```

其中最关键的剪枝条件就是：

```text
left < n       // 左括号不能超过 n 个
right < left   // 右括号不能超过左括号
```

这两个条件想明白了，基本就能重新推导出整道题。
