# 深拷贝和浅拷贝的区别以及实现思路

**浅拷贝：**只复制对象/数组的**第一层属性**。如果某个属性是引用类型（如对象、数组），拷贝的只是该引用的地址，原对象和拷贝对象的该属性指向**同一块内存**。

➜ 修改拷贝对象中的这个嵌套对象，原对象也会跟着变。

**深拷贝：**递归复制所有层级的属性，生成一个与原对象完全独立的新对象。无论嵌套多深，所有引用类型都会被复制一份全新的数据。

➜ 修改拷贝对象，**完全不会影响**原对象。  

浅拷贝实现：

- 数组：slice()、concat()、展开运算符[...arr]、Array.from(arr)
- 对象:Object.assign({}, obj),、展开运算符`{...obj}`

深拷贝实现：

- JSON 方式：JSON.parse(JSON.stringify(obj))
- 浏览器原生深拷贝：structuredClone(obj)
