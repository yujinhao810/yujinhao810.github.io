# CSS定位

## 一、先记住 position 的 5 个值 {#kaj-h-34d9dc3e-e916-42ba-9cba-b1443fc21fe7}

| position | 核心理解 | 是否脱离普通文档流 | 定位参考 |
| --- | --- | --- | --- |
| `static` | 默认正常布局 | ❌ | 无 |
| `relative` | 在原位置基础上偏移 | ❌ | 自身原来的位置 |
| `absolute` | 脱离文档流进行定位 | ✅ | 最近的定位祖先 |
| `fixed` | 相对于视口固定 | ✅ | 通常是 viewport |
| `sticky` | 在 relative 和 fixed 之间切换 | ❌/视其工作方式理解 | 滚动容器 |

最核心的记忆：

> **static：正常放**  
> **relative：原地挪**  
> **absolute：找祖先定位**  
> **fixed：钉在视口**  
> **sticky：滚到阈值后粘住**
> 
> 
> 
> ## 二、`static`：默认定位 {#kaj-h-7cfdc4c0-7472-43d9-bfb3-3ade9723f0c8}
> 
> 
> 
> ```text
> position: static;
> ```
> 
> 
> 
> 就是正常的文档流。
> 
> 
> 
> 此时：
> 
> 
> 
> ```text
> top
> left
> right
> bottom
> z-index
> ```
> 
> 
> 
> 对普通定位没有作用。
> 
> 
> 
> 例如：
> 
> 
> 
> ```text
> A
> B
> C
> ```
> 
> 
> 
> 按照正常文档流排列。
> 
> 
> 
> 所以面试简单说：
> 
> 
> 
> > `static` 是 `position` 的默认值，元素按照正常文档流进行布局，`top`、`left`、`right`、`bottom` 等偏移属性对其不起作用。
> > 
> > 
> > 
> > ## 三、`relative`：相对于自己原来的位置移动 {#kaj-h-889179d6-1034-4c74-a208-8117d84ad250}
> > 
> > 
> > 
> > ```text
> > .child {
> >     position: relative;
> >     top: 20px;
> >     left: 30px;
> > }
> > ```
> > 
> > 
> > 
> > 可以理解成：
> > 
> > 
> > 
> > > **先按照正常文档流把我放好，然后在这个位置上移动。**
> > 
> > 
> > 
> > 例如原来：
> > 
> > 
> > 
> > ```text
> > A
> > B
> > C
> > ```
> > 
> > 
> > 
> > B：
> > 
> > 
> > 
> > ```text
> > top: 20px;
> > ```
> > 
> > 
> > 
> > 相当于：
> > 
> > 
> > 
> > ```text
> > A
> > 
> >    B ← 向下移动20px
> > 
> > C
> > ```
> > 
> > 
> > 
> > 但是有一个非常重要的特点：
> > 
> > 
> > 
> > > **relative 虽然视觉上移动了，但原来的位置仍然保留。**
> > 
> > 
> > 
> > 所以它**不会脱离普通文档流**。
> > 
> > 
> > 
> > 这也是 `relative` 和 `absolute` 最重要的区别之一。
> > 
> > 
> > 
> > ## 四、`absolute`：相对于最近的定位祖先 {#kaj-h-1e74455a-bdc0-47b3-bf9c-fc7bde450cbc}
> > 
> > 
> > 
> > ```text
> > .child {
> >     position: absolute;
> > }
> > ```
> > 
> > 
> > 
> > 它会：
> > 
> > 
> > 
> > > **脱离普通文档流，不再占据原来的空间。**
> > 
> > 
> > 
> > 然后浏览器寻找它的**最近的定位祖先**。
> > 
> > 
> > 
> > 所谓定位祖先，通常就是：
> > 
> > 
> > 
> > ```text
> > position: relative;
> > position: absolute;
> > position: fixed;
> > ```
> > 
> > 
> > 
> > 例如：
> > 
> > 
> > 
> > ```html
> > <div class="parent">
> >     <div class="child"></div>
> > </div>
> > ```
> > 
> > 
> > 
> > ```text
> > .parent {
> >     position: relative;
> > }
> > 
> > .child {
> >     position: absolute;
> >     top: 0;
> >     left: 0;
> > }
> > ```
> > 
> > 
> > 
> > 那么：
> > 
> > 
> > 
> > ```text
> > parent
> > ┌──────────────────────────┐
> > │ child                    │
> > │                          │
> > │                          │
> > └──────────────────────────┘
> > ```
> > 
> > 
> > 
> > `child` 就以 `.parent` 作为定位参考。
> > 
> > 
> > 
> > 这也是实际开发中特别经典的组合：
> > 
> > 
> > 
> > ```text
> > .parent {
> >     position: relative;
> > }
> > 
> > .child {
> >     position: absolute;
> > }
> > ```
> > 
> > 
> > 
> > 例如：
> > 
> > 
> > 
> > - 父元素作为卡片
> > - 子元素作为右上角删除按钮
> > - 子元素作为角标
> > - 下拉菜单
> > - 弹出层内部定位
> > 
> > 
> > 
> > ## 五、`fixed`：相对于视口固定 {#kaj-h-85ca131f-a7c2-4ab9-8c03-6823faf2c136}
> > 
> > 
> > 
> > ```text
> > .back-top {
> >     position: fixed;
> >     right: 20px;
> >     bottom: 20px;
> > }
> > ```
> > 
> > 
> > 
> > 可以理解成：
> > 
> > 
> > 
> > > **把元素钉在浏览器视口的某个位置。**
> > 
> > 
> > 
> > 比如：
> > 
> > 
> > 
> > ```text
> > 浏览器窗口
> > ┌─────────────────────────┐
> > │                         │
> > │                         │
> > │                         │
> > │                         │
> > │                    ┌──┐ │
> > │                    │↑ │ │
> > │                    └──┘ │
> > └─────────────────────────┘
> > ```
> > 
> > 
> > 
> > 即使页面滚动：
> > 
> > 
> > 
> > ```text
> > 滚动前：
> >                  ↑
> >                  ↑
> >               固定按钮
> > 
> > 
> > 滚动后：
> >                  ↑
> >                  ↑
> >               固定按钮
> > ```
> > 
> > 
> > 
> > 按钮仍然在视口右下角。
> > 
> > 
> > 
> > 所以非常适合：
> > 
> > 
> > 
> > - 返回顶部
> > - 悬浮按钮
> > - 固定导航
> > - 悬浮客服
> > - 固定工具栏
> > 
> > 
> > 
> > ## 六、这里纠正你原来的一个说法 {#kaj-h-8bd33c02-07ec-4ec3-846b-b671f97807f0}
> > 
> > 
> > 
> > 你写：
> > 
> > 
> > 
> > > `fixed` 具有破坏性，会导致其他元素位置的变化。
> > 
> > 
> > 
> > 这个说法**不准确**。
> > 
> > 
> > 
> > `fixed` 和 `absolute` 一样，都是：
> > 
> > 
> > 
> > > **脱离普通文档流。**
> > 
> > 
> > 
> > 所以它们**不会占据原来的文档流空间**。
> > 
> > 
> > 
> > 例如：
> > 
> > 
> > 
> > ```text
> > A
> > B(fixed)
> > C
> > ```
> > 
> > 
> > 
> > 布局时，普通流可能相当于：
> > 
> > 
> > 
> > ```text
> > A
> > C
> > ```
> > 
> > 
> > 
> > `B` 脱离了普通流，浮在上面。
> > 
> > 
> > 
> > 所以更准确的说法是：
> > 
> > 
> > 
> > > `fixed` 脱离普通文档流，不再占据原来的布局空间，因此可能覆盖其他元素，但通常不会直接导致其他普通流元素重新排布。
> > 
> > 
> > 
> > ## 七、`absolute` 和 `fixed` 最重要的区别 {#kaj-h-87c4d5bf-4fce-46d7-b1dc-21b2e17a7d65}
> > 
> > 
> > 
> > 这是面试高频题。
> > 
> > 
> > 
> > ### absolute {#kaj-h-f117bfc3-78e5-4d45-a42e-732e034e91df}
> > 
> > 
> > 
> > ```text
> > position: absolute;
> > ```
> > 
> > 
> > 
> > 核心：
> > 
> > 
> > 
> > > **相对于最近的定位祖先定位。**
> > 
> > 
> > 
> > 例如：
> > 
> > 
> > 
> > ```text
> > body
> >  └── parent(relative)
> >       └── child(absolute)
> > ```
> > 
> > 
> > 
> > 那么：
> > 
> > 
> > 
> > ```text
> > child
> >   ↓
> > parent
> > ```
> > 
> > 
> > 
> > ---
> > 
> > 
> > 
> > ### fixed {#kaj-h-8cb71f44-1d1a-4807-a83f-9fee8517b63c}
> > 
> > 
> > 
> > ```text
> > position: fixed;
> > ```
> > 
> > 
> > 
> > 核心：
> > 
> > 
> > 
> > > **相对于视口定位，并且滚动页面时通常保持在视口的固定位置。**
> > 
> > 
> > 
> > 所以：
> > 
> > 
> > 
> > ```text
> > absolute → 找定位祖先
> > fixed    → 通常看 viewport
> > ```
> > 
> > 
> > 
> > ## 八、`sticky`：粘性定位 {#kaj-h-96107339-b689-4195-ae6c-ad1a3cb38768}
> > 
> > 
> > 
> > 这个可以理解成：
> > 
> > 
> > 
> > > **先正常跟着文档流走，滚动到指定阈值后“粘住”。**
> > 
> > 
> > 
> > 例如：
> > 
> > 
> > 
> > ```text
> > .nav {
> >     position: sticky;
> >     top: 0;
> > }
> > ```
> > 
> > 
> > 
> > 开始：
> > 
> > 
> > 
> > ```text
> > ┌──────────────┐
> > │ header       │
> > │ nav          │
> > │ content      │
> > │ content      │
> > └──────────────┘
> > ```
> > 
> > 
> > 
> > 正常情况下 `nav` 就像普通元素一样。
> > 
> > 
> > 
> > 当页面向下滚动：
> > 
> > 
> > 
> > ```text
> >         nav
> >         ↓
> > ──────────────
> >      top: 0
> >         ↓
> >      粘住
> > ```
> > 
> > 
> > 
> > 于是表现得类似：
> > 
> > 
> > 
> > ```text
> > position: fixed;
> > top: 0;
> > ```
> > 
> > 
> > 
> > 但它**不是简单的 fixed**。
> > 
> > 
> > 
> > 它仍然受到其滚动容器和包含块范围的限制。
> > 
> > 
> > 
> > ## 九、position 和 float、display 的关系 {#kaj-h-5976169e-e6df-48db-86ce-4167f9b049c0}
> > 
> > 
> > 
> > 你这部分不用背那么复杂。
> > 
> > 
> > 
> > 面试记住：
> > 
> > 
> > 
> > > `position: absolute/fixed` **会让元素脱离普通文档流，因此 float 对它们不再起作用。**
> > 
> > 
> > 
> > 例如：
> > 
> > 
> > 
> > ```text
> > .child {
> >     float: left;
> >     position: absolute;
> > }
> > ```
> > 
> > 
> > 
> > 这时候主要按照 `absolute` 的定位规则处理，`float` 不再发挥作用。
> > 
> > 
> > 
> > 另外：
> > 
> > 
> > 
> > > `absolute/fixed` 元素的 `display` 会发生相应的计算值转换，例如行内元素设置绝对定位后，不再表现为普通 inline 元素。
> > 
> > 
> > 
> > 实际面试一般不会要求你完整背 `display` 转换规则。
> > 
> > 
> > 
> > ## 十、最终面试版总结 {#kaj-h-ad355de3-7dfa-4ec1-9037-8d714ddbcef5}
> > 
> > 
> > 
> > 你可以直接背下面这段：
> > 
> > 
> > 
> > > CSS 中 `position` 常见有 `static`、`relative`、`absolute`、`fixed` 和 `sticky` 五种。
> > > 
> > > 
> > > 
> > > `static` 是默认值，元素按照正常文档流布局，`top`、`left` 等定位属性不起作用。
> > > 
> > > 
> > > 
> > > `relative` 不会脱离文档流，可以相对于元素原来的位置进行偏移，原来的空间仍然保留。同时它经常用于给子元素的 `absolute` 定位提供参考。
> > > 
> > > 
> > > 
> > > `absolute` 会脱离普通文档流，相对于最近的定位祖先进行定位，如果没有定位祖先，则通常相对于初始包含块进行定位。
> > > 
> > > 
> > > 
> > > `fixed` 也会脱离普通文档流，通常相对于浏览器视口进行定位，页面滚动时仍保持在视口的固定位置。
> > > 
> > > 
> > > 
> > > `sticky` 可以理解为一种粘性定位，元素正常情况下参与文档流，当滚动到指定阈值后，在允许的范围内保持粘住的效果。
> > > 
> > > 
> > > 
> > > 简单来说就是：**relative 是原地移动，absolute 是相对于定位祖先定位，fixed 是相对于视口固定，sticky 是滚动到阈值后粘住。**
> > 
> > 
> > 
> > ### 最后给你一个非常好记的对比 {#kaj-h-f186394b-789a-41b6-9242-e180d67a5b94}
> > 
> > 
> > 
> > ```text
> > static
> >   ↓
> > 正常放
> > 
> > relative
> >   ↓
> > 原地挪
> >   ↓
> > 原来的位置还在
> > 
> > absolute
> >   ↓
> > 脱离文档流
> >   ↓
> > 找最近定位祖先
> > 
> > fixed
> >   ↓
> > 脱离文档流
> >   ↓
> > 钉在 viewport
> > 
> > sticky
> >   ↓
> > 正常参与文档流
> >   ↓
> > 滚动到阈值
> >   ↓
> > 粘住
> > ```
> > 
> > 
> > 
> > **面试重点优先级：**
> > 
> > 
> > 
> > > `relative` vs `absolute` ＞ `absolute` vs `fixed` ＞ `sticky` ＞ `static` ＞ `display/float/position` 的细节规则。
